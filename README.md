# Bechdel Movie Challenge

**Test the Classics** is a web game where players guess each film’s Bechdel rating, earn points, and build streaks.

I built it as a small product experiment exploring how static cultural data can become something faster, more visual, and more playful.

## Why I built it

The Bechdel Test is widely discussed, but it is usually encountered as a label or dataset.

I wanted to turn that into a lightweight guessing game where movie fans can test their intuition, discover surprising results, and learn more about female representation in films along the way.

## What it does

- Guess whether a movie passes the Bechdel Test
- Earn points and build streaks
- Move quickly through the game with keyboard controls
- Reveal contextual information after each guess
- Persist scoring locally between sessions
- Pull movie data from external APIs

## Data + APIs

The prototype combines:

- Bechdel Test data
- TMDB movie data
- Local Storage for persistent scoring

## What I was exploring

- turning a static dataset into a game mechanic
- designing for speed and low-friction interaction
- keyboard-first UX
- reveal states that teach without interrupting play
- combining multiple APIs in a client-side prototype
- using a small custom component system to keep the experience visually consistent

## Visuals

Illustrations were generated with Midjourney and adapted into the product experience.

## Tech

- Next.js
- REST APIs
- Local Storage
- State Management
- Custom Component Library
- Midjourney
